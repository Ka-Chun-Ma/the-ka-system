# The Ka System

An interactive personal showcase for Ka, exploring data systems, AI workflows, learning, independent experiments, and the long game.

## Design direction

The site uses a central stylised portrait as a navigation hub. Six orbiting threads lead to different parts of Ka's public thinking and evidence. The visual language takes inspiration from immersive WebGL editorial experiences while keeping a direct navigation path for recruiters and LinkedIn visitors.

## Current prototype

- Vanilla HTML, CSS and JavaScript
- Responsive radial navigation
- Ka's LinkedIn portrait framed as a 3D-style scene anchor
- Branch detail panel with keyboard-accessible buttons
- Reduced dependency surface for early Sites deployment

## Next iteration

1. Replace the portrait placeholder with Ka's approved portrait or 3D asset.
2. Add real project case-study routes and GitHub links.
3. Introduce WebGL or React Three Fiber only after the interaction model is validated.
4. Add a mobile-specific, reduced-motion experience.

## Privacy boundary

Public examples should use open, synthetic, or anonymised data. Government systems, private financial details, and personal trading records remain outside the public site.
